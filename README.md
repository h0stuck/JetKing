# JetKing

## 오리, 날다

**오리, 날다**는 Unity 2D로 개발된 항아리류 플랫포머 게임입니다.  
플레이어는 제트팩을 멘 오리를 조종하여 장애물을 넘어 점점 더 높은 곳으로 올라가야 합니다.

게임의 목표는 가장 높은 곳에 있는 목적지까지 도달하는 것입니다.

---

## 게임 소개

오리는 제트팩을 사용해 하늘로 날아오를 수 있습니다.  
하지만 제트팩에는 연료가 존재하며, 비행 중에는 연료가 계속 소모됩니다.

연료가 부족하거나 벽에 잘못 부딪히면 추락할 수 있기 때문에,  
플레이어는 지형과 연료를 신중하게 고려하며 위로 올라가야 합니다.

---

## 주요 특징

- Unity 2D 기반 플랫포머 게임
- 제트팩을 이용한 상승 이동
- 연료 소모 및 충전 시스템
- 연료팩 획득을 통한 제트팩 충전
- 벽 충돌 시 제트팩 비활성화
- 추락 위험이 있는 항아리류 게임 구조
- 가장 높은 곳의 목적지에 도달하는 것을 목표로 하는 스테이지 구성

---

## 게임 규칙

### 제트팩 연료

오리가 비행하는 동안 제트팩의 연료가 소모됩니다.

연료는 다음 상황에서 충전됩니다.

- 바닥에 서 있을 때
- 연료팩을 획득했을 때

### 벽 충돌

비행 중 경사면이 아닌 벽에 닿으면 제트팩이 꺼집니다.  
제트팩이 꺼지면 오리는 더 이상 비행할 수 없고 아래로 추락하게 됩니다.

따라서 벽에 직접 부딪히지 않도록 조심하면서 이동해야 합니다.

---

## 게임 목표

플레이어의 최종 목표는 오리를 조종해  
맵의 가장 높은 곳에 있는 목적지에 도달하는 것입니다.

중간에 추락하면 다시 올라가야 하므로,  
정확한 조작이 중요합니다.

---

## 사용 기술

- Unity 2D
- C#
- Rigidbody2D
- Collider2D
- 2D Platformer Movement

---

## 개발 목적

이 프로젝트는 Unity 2D 환경에서  
제트팩 이동, 연료 관리, 충돌 판정, 추락 리스크를 활용한  
항아리류 플랫포머 게임을 구현하는 것을 목표로 합니다.

단순한 점프 게임이 아니라,  
비행 각도와 연료 사용 타이밍을 고려해야하는  
긴장감 있는 상승형 게임플레이를 만드는 데 중점을 두었습니다.
